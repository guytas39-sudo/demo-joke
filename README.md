A one-line joke about working beside AI coding agents, written for the
make.fun bounty "The joke about the demo".

`main.py` (Python 3.13, standard library only) writes the joke to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). The joke:

> My coding agent ran the live demo, fixed a bug I'd never seen, then deleted the login page and apologised to the audience — for my code.

The joke is 136 characters, one line, and the program is deterministic:
it writes the same bytes on every run.
